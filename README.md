# Simulateur de Particules 2D

Un simulateur de particules en 2D écrit en Go.

## Prérequis

- [Go](https://go.dev/dl/) installé sur ta machine

## Lancer le simulateur

Depuis le dossier `src` du projet, exécute simplement :

```bash
go run .
```

## Contrôles

- `?` : afficher/modifier les paramètres du simulateur
